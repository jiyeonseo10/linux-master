# Process Fork & Exec

## 1. fork()

`fork()`는 **현재 프로세스를 복제하여 새로운 프로세스를 생성**하는 함수이다.

- 기존 프로세스 → 부모 프로세스(Parent Process)
- 새로 생성된 프로세스 → 자식 프로세스(Child Process)
- 새 프로세스를 위한 메모리가 할당됨
- 처음에는 부모와 자식이 같은 코드를 가진다

```text
Parent Process
     |
   fork()
     |
Child Process
```

### 핵심

```text
fork
→ 프로세스 복제
→ 부모 프로세스 + 자식 프로세스
```

---

## 2. exec()

`exec()`는 현재 프로세스의 내용을 **새로운 프로그램으로 교체**한다.

- 기존 프로세스의 메모리에 새로운 프로그램 코드를 덮어씀
- 새 메모리를 별도로 할당하지 않음
- 기존 프로그램 대신 새로운 프로그램이 실행됨

```text
기존 프로세스
     ↓
   exec()
     ↓
새 프로그램으로 교체
```

### 핵심

```text
exec
→ 기존 프로세스를 새 프로그램으로 교체
→ 새 프로세스를 복제하는 방식이 아님
```

---

## 3. fork와 exec 비교

| 구분 | fork() | exec() |
|---|---|---|
| 핵심 | 복제 | 교체 |
| 새 프로세스 생성 | O | X |
| 부모/자식 프로세스 | 생성됨 | 별도로 생성되지 않음 |
| 기존 프로그램 | 유지 | 새 프로그램으로 대체 |

```text
fork = 복제
exec = 교체
```
