# Process Priority - nice & renice

## 1. nice

`nice`는 **프로세스의 우선순위를 확인하고 변경할 수 있는 명령어**이다.

NI 값을 조정하여 프로세스의 우선순위를 변경한다.

형식:

```bash
nice [옵션] 프로세스명
```

---

## 2. NI 값과 우선순위

NI 값의 범위:

```text
-20 ~ 19
```

```text
-20 → 가장 높은 우선순위
19  → 가장 낮은 우선순위
```

즉,

```text
NI 값이 작을수록 → 우선순위 높음
NI 값이 클수록   → 우선순위 낮음
```

기본 우선순위 값은 `0`이다.

---

## 3. nice 주요 옵션

책에 나온 형식:

```text
-n 조정수치
-조정수치
--adjustment 조정수치
```

명령의 기존 우선권에 조정수치를 더한다.

옵션 `-n`을 사용하지 않으면 기본적으로 `10`을 사용한다.

예:

```bash
nice -10 bash
```

```text
NI 값을 10 증가
→ 우선순위 낮아짐
```

우선순위를 높이는 예:

```bash
nice --10 bash
```

```text
NI 값을 -10만큼 조정
→ 우선순위 높아짐
```

---

## 4. 일반 사용자와 root

```text
일반 사용자
→ nice 값을 증가시킬 수 있음
→ 우선순위를 낮출 수 있음

root
→ nice 값을 감소시킬 수 있음
→ 우선순위를 높일 수 있음
```

---

# 5. renice

`renice`는 **이미 실행 중인 프로세스의 우선순위를 변경하는 명령어**이다.

형식:

```bash
renice [옵션] NI값 PID
```

---

## 6. renice 주요 옵션

| 옵션 | 의미 |
|---|---|
| `-p` | 프로세스 ID 지정 |
| `-u` | 사용자명 지정 |
| `-g` | 프로세스 GID 지정 |

---

## 7. nice와 renice 차이

```text
nice
→ 프로세스 실행 시 우선순위 조정
→ 기존 NI값을 증감

renice
→ 이미 실행 중인 프로세스 우선순위 변경
→ 지정한 NI값으로 설정
```

예:

```bash
renice -20 3241
```

```text
PID 3241 프로세스의 NI값을 -20으로 변경
```

---

# 핵심 정리

```text
NI 범위
→ -20 ~ 19

-20 → 가장 높은 우선순위
19  → 가장 낮은 우선순위

NI 값 작음 → 우선순위 높음
NI 값 큼   → 우선순위 낮음
```

```text
nice
→ 실행할 프로세스의 우선순위 조정
→ 기본 조정값 10

renice
→ 실행 중인 프로세스 우선순위 변경

-p → PID
-u → 사용자명
-g → GID
```
