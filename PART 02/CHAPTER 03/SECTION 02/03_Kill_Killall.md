# Process Kill & Killall

## 1. kill

`kill`은 **프로세스를 종료시키는 명령어**이다.

형식:

```bash
kill [옵션] [시그널번호 또는 시그널이름] [PID 또는 %작업번호]
```

---

## 2. kill 주요 옵션

| 옵션 | 의미 |
|---|---|
| `-l` | 시그널 종류 나열 |
| `-s 시그널번호` | 전달할 시그널 종류 지정 |
| `-s 시그널명` | 전달할 시그널 종류 지정 |
| `-1` | HUP 시그널, 프로세스 재시작 |
| `-9` | 프로세스 강제 종료 |

### 예시

```bash
kill -9 2997
```

```text
PID 2997 프로세스 강제 종료
```

### 핵심

```text
kill -l → 시그널 종류 나열
kill -1 → HUP → 재시작
kill -9 → 강제 종료
```

---

## 3. killall

`killall`은 **같은 데몬의 여러 프로세스를 한 번에 종료할 때 사용하는 명령어**이다.

프로세스명으로 연관된 프로세스들을 종료한다.

형식:

```bash
killall [옵션] 프로세스명
```

---

## 4. killall 주요 옵션

| 옵션 | 의미 |
|---|---|
| `-g` | 그룹을 지정하여 프로세스 종료 |
| `-i` | 프로세스 종료 전 확인 메시지 표시 |
| `-l` | 시그널 목록 표시 |
| `-v` | 상세 정보 표시 |

### 핵심

```text
-g → 그룹 지정
-i → 종료 전 확인
-l → 시그널 목록
-v → 상세 정보
```

---

## 5. kill과 killall 비교

```text
kill
→ PID를 기준으로 프로세스에 시그널 전달

killall
→ 프로세스명을 기준으로 관련 프로세스 종료
```

---

# 핵심 정리

```text
kill -1
→ HUP
→ 프로세스 재시작

kill -9
→ 강제 종료
```

```text
killall -g → 그룹 지정
killall -i → 종료 전 확인
killall -l → 시그널 목록
killall -v → 상세 정보
```
