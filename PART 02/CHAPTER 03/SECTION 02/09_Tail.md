# Output Monitoring - tail

## 1. tail

`tail`은 **파일의 마지막 부분을 출력하는 명령어**이다.

기본적으로 마지막 **10줄**을 출력한다.

형식:

```bash
tail [옵션] [파일명]
```

---

## 2. 기본 사용

```bash
tail 파일명
```

```text
→ 파일의 마지막 10줄 출력
```

---

## 3. 주요 옵션

| 옵션 | 의미 |
|---|---|
| `-f` | 마지막 10줄을 출력한 뒤, 추가되는 내용을 실시간으로 출력 |
| `-n N` | 마지막에서 N개의 라인 출력 |

---

## 4. 예시

### 마지막 5줄 출력

```bash
tail -n 5 /etc/passwd
```

```text
→ /etc/passwd의 마지막 5줄 출력
```

### 실시간 출력

```bash
tail -f 파일명
```

```text
→ 마지막 10줄 출력
→ 이후 추가되는 내용을 실시간으로 확인
```

---

# 핵심 정리

```text
tail
→ 파일의 마지막 부분 출력
→ 기본 마지막 10줄
```

```text
-n N
→ 마지막 N줄 출력

-f
→ 마지막 10줄 출력 후
→ 추가되는 내용 실시간 출력
```
