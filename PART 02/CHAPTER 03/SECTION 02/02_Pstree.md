# Process Tree (pstree)

## 1. pstree

`pstree`는 **실행 중인 프로세스들을 트리 구조로 보여주는 명령어**이다.

부모 프로세스와 자식 프로세스의 관계를 구조적으로 확인할 수 있다.

```bash
pstree [옵션]
```

---

## 2. 주요 옵션

| 옵션 | 의미 |
|---|---|
| `-p` | 프로세스 ID 표시 |
| `-n` | 프로세스 ID를 정렬해서 표시 |
| `-a` | 명령행 인자를 포함해서 표시 |
| `-h` | 현재 프로세스와 부모 프로세스를 강조해서 표시 |

---

## 3. 예시

### PID 표시

```bash
pstree -p
```

```text
-p
→ PID 표시
```

### PID 정렬

```bash
pstree -n
```

```text
-n
→ PID 기준 정렬
```

### 명령행 인자 표시

```bash
pstree -a
```

```text
-a
→ 명령행 인자 포함
```

### 현재 프로세스와 부모 강조

```bash
pstree -h
```

```text
-h
→ 현재 프로세스와 부모 프로세스 강조
```

---

# 핵심 정리

```text
pstree
→ 실행 중인 프로세스를 트리 구조로 표시

-p → PID 표시
-n → PID 정렬
-a → 명령행 인자 포함
-h → 현재 프로세스와 부모 프로세스 강조
```
