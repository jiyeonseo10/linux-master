# Process Status (ps)

## 1. ps(Process Status)

`ps`는 **현재 실행 중인 프로세스의 상태를 보여주는 명령어**이다.

- 현재 실행 중인 프로세스 정보 확인
- CPU 사용도가 낮은 순서로 출력

형식:

```bash
ps [옵션]
```

옵션 없이 실행하면 자신의 터미널에서 실행 중인 프로세스 정보만 나타난다.

---

## 2. ps 기본 출력 항목

| 항목 | 의미 |
|---|---|
| `PID` | 프로세스 식별번호 |
| `TTY` | 프로세스와 연결된 터미널 번호 |
| `TIME` | 총 CPU 사용 시간 |
| `CMD` | 실행 명령 |

```text
PID  → 프로세스 식별번호
TTY  → 연결된 터미널 번호
TIME → 총 CPU 사용 시간
CMD  → 실행 명령
```

---

## 3. ps 주요 옵션

| 옵션 | 의미 |
|---|---|
| `a` | 현재 실행 중인 모든 프로세스 출력 |
| `e` | 모든 프로세스 정보 출력 |
| `u` | 사용자 이름과 프로세스 시작 시간 출력 |
| `x` | 접속된 터미널뿐 아니라 사용 중인 모든 프로세스 출력 |
| `l` | 자세한 정보 출력 |

---

## 4. ps와 grep

특정 프로세스의 상태를 확인할 때 `grep`과 함께 사용할 수 있다.

```bash
ps ax | grep httpd
```

```text
ps ax | grep httpd
→ httpd 프로세스 상태 확인
```

---

## 5. ps aux 출력 항목

| 항목 | 의미 |
|---|---|
| `USER` | 프로세스 소유자명 |
| `PID` | 프로세스 식별번호 |
| `%CPU` | CPU 사용 비율의 추정치 |
| `%MEM` | 메모리 사용 비율의 추정치 |
| `VSZ` | 페이지 단위의 가상메모리 사용량 |
| `RSS` | 실제 사용된 메모리량 |
| `TTY` | 프로세스와 연결된 터미널 번호 |
| `STAT` | 현재 프로세스 상태 |
| `START` | 프로세스 시작 시간 |
| `TIME` | 총 CPU 사용 시간 |
| `COMMAND` | 실행 명령 |

### 핵심

```text
VSZ → 가상메모리 사용량
RSS → 실제 사용 메모리량
STAT → 현재 프로세스 상태
START → 프로세스 시작 시간
TIME → 총 CPU 사용 시간
```

---

## 6. 프로세스 상태값(STAT)

| 상태 | 의미 |
|---|---|
| `P` | 수행 가능 / 수행 중 |
| `R` | 현재 실행 상태 |
| `S` | 잠든 상태 |
| `D` | I/O 작업이 끝나기를 기다리면서 정지된 상태 |
| `T` | 정지된 상태, 일시 정지 상태 |
| `Z` | 좀비 프로세스 |

### 좀비 프로세스

작업 종료 후 부모 프로세스로부터 회수되지 않아 메모리에 남아 있는 상태이다.

```text
Z
→ Zombie
→ 작업은 끝났지만 정상적으로 회수되지 않은 상태
```

---

## 7. ps -l

`ps -l`은 프로세스의 **자세한 정보**를 출력한다.

| 항목 | 의미 |
|---|---|
| `F` | 프로세스 플래그 |
| `S` | 프로세스 상태 |
| `UID` | 프로세스 소유자의 Username |
| `PPID` | 부모 프로세스 PID |
| `C` | 짧은 시간 동안의 CPU 사용률 |
| `PRI` | 실행 우선순위 값 |
| `NI` | NICE 우선순위를 계산할 때 사용되는 nice값 |
| `ADDR` | 프로세스의 주기억장치 내 주소 |
| `SZ` | 프로세스 크기 |
| `WCHAN` | 프로세스가 대기 중인 위치 |

### 핵심

```text
PID  → 현재 프로세스 ID
PPID → 부모 프로세스 PID

PRI → 실행 우선순위 값
NI  → nice 값
```

# 핵심 정리

```text
ps
→ 현재 실행 중인 프로세스 상태 확인

기본 출력
→ PID / TTY / TIME / CMD

a → 현재 실행 중인 모든 프로세스
e → 모든 프로세스 정보
u → 사용자 이름 + 시작 시간
x → 터미널에 연결되지 않은 프로세스까지
l → 자세한 정보
```

```text
VSZ → 가상메모리
RSS → 실제 메모리

R → 실행
S → 잠듦
T → 정지
Z → 좀비

PPID → 부모 프로세스 PID
```
