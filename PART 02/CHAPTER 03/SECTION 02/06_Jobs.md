# Job Control - jobs

## 1. jobs

`jobs`는 현재 셸에서 관리 중인 작업의 상태를 확인하는 명령어이다.

확인할 수 있는 상태:

- 작업이 중지된 상태
- 백그라운드에서 진행 중인 상태
- 상태가 변경되었지만 아직 보고되지 않은 상태

형식:

```bash
jobs [옵션] [작업번호]
```

---

## 2. jobs 주요 옵션

| 옵션 | 의미 |
|---|---|
| `-l` | 프로세스 그룹 ID를 state 필드 앞에 표시 |
| `-n` | 프로세스 그룹 중 대표 프로세스 ID 표시 |
| `-p` | 프로세스 ID를 한 행씩 표시 |

### 핵심

```text
-l → 프로세스 그룹 ID 표시
-n → 대표 프로세스 ID 표시
-p → 프로세스 ID를 한 행씩 표시
```

---

## 3. 작업번호

`jobs` 출력에서 대괄호 안의 숫자는 작업번호이다.

예:

```text
[1]+ Stopped
[2]- Running
```

```text
[1], [2]
→ 작업번호
```

---

## 4. + 와 -

`jobs` 출력에서:

```text
+ → 현재 작업
- → 다음에 실행될 작업
```

예:

```text
[1]+
→ 현재 작업

[2]-
→ 다음에 실행될 작업
```

---

## 5. 작업 상태

| 상태 | 의미 |
|---|---|
| `Running` | 작업이 중단되지 않고 계속 진행 중 |
| `Stopped` | 작업이 일시 중단 |
| `Done` | 작업이 완료되어 0을 반환하고 종료 |
| `Done(code)` | 작업이 완료되었으며 0이 아닌 코드를 반환 |

---

# 핵심 정리

```text
jobs
→ 현재 셸에서 작업 상태 확인
```

```text
-l → 프로세스 그룹 ID 표시
-n → 대표 프로세스 ID 표시
-p → 프로세스 ID를 한 행씩 표시
```

```text
+ → 현재 작업
- → 다음에 실행될 작업
```

```text
Running → 실행 중
Stopped → 일시 중단
Done → 0 반환 후 종료
Done(code) → 0이 아닌 코드 반환 후 종료
```
