# Process Monitoring - top

## 1. top

`top`은 **리눅스 시스템의 운영 상태를 실시간으로 모니터링하거나 프로세스 상태를 확인하는 명령어**이다.

형식:

```bash
top [옵션] [PID]
```

기본적으로 **5초에 한 번씩** 시스템 상태 정보가 갱신된다.

---

## 2. top 주요 옵션

| 옵션 | 의미 |
|---|---|
| `-d 시간` | 실시간 화면 출력 시간 지정(초 단위) |
| `-p PID` | 모니터링할 프로세스 ID 지정 |

예:

```bash
top -d 3
```

```text
3초 간격으로 화면 갱신
```

```bash
top -p 1707
```

```text
PID 1707 프로세스 모니터링
```

---

## 3. top 출력 항목

| 항목 | 의미 |
|---|---|
| `PID` | 프로세스 식별번호 |
| `USER` | 프로세스 소유자 |
| `PR` | 프로세스 우선순위 |
| `NI` | 프로세스 NICE값 |
| `VIRT` | 가상 메모리 총량 |
| `RES` | 물리적 메모리 사용량 |
| `SHR` | 공유 메모리 총량 |
| `S` | 프로세스 상태 |
| `%CPU` | CPU 사용률 |
| `%MEM` | 메모리 사용률 |
| `TIME+` | CPU 사용 시간 |
| `COMMAND` | 실행 명령 |

### 핵심

```text
PR   → 프로세스 우선순위
NI   → NICE값
VIRT → 가상 메모리
RES  → 물리 메모리
SHR  → 공유 메모리
```

---

## 4. 프로세스 상태

| 상태 | 의미 |
|---|---|
| `D` | 중단될 수 없는 Sleep 상태 |
| `R` | 실행 중인 상태 |
| `S` | 휴면 상태 |
| `T` | Trace되거나 정지된 프로세스 |
| `Z` | 좀비 프로세스 |

```text
R → Running
S → Sleeping
Z → Zombie
```

---

## 5. top 실행 중 사용하는 명령

| 명령 | 의미 |
|---|---|
| `h` 또는 `?` | 도움말 확인 |
| `t` | CPU와 프로세스 정보 표시/감춤 |
| `i` | 좀비 프로세스 정보 표시/감춤 |
| `n 수치` | 지정한 개수만큼 프로세스 표시 |
| `r 조정치` | renice 값을 변경하여 실행 우선순위 조정 |
| `k PID` | 지정된 PID 종료 |
| `q` 또는 `Ctrl + C` | top 종료 |

---

# 핵심 정리

```text
top
→ 시스템 운영 상태와 프로세스를 실시간 모니터링
→ 기본 5초마다 갱신
```

```text
-d → 갱신 시간 지정
-p → 특정 PID 모니터링
```

```text
VIRT → 가상 메모리
RES  → 물리 메모리
SHR  → 공유 메모리
```

```text
r → 우선순위 조정
k → PID 종료
q 또는 Ctrl + C → top 종료
```
