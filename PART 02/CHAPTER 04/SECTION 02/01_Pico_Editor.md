# Pico Editor

## 1. pico

`pico`는 유닉스 기반의 텍스트 에디터이다.

형식:

```bash
pico [옵션] [파일명]
```

---

## 2. 주요 옵션

| 옵션 | 의미 |
|---|---|
| `-w` | 긴 라인에서 라인이 깨지는 경우에 사용 |

---

## 3. 주요 단축키

| 단축키 | 기능 |
|---|---|
| `Ctrl + O` | 파일 저장 |
| `Ctrl + X` | 파일 종료 |
| `Ctrl + R` | 현재 커서 위치에 다른 파일 불러오기 |
| `Ctrl + A` | 현재 행의 맨 앞으로 이동 |
| `Ctrl + E` | 현재 행의 맨 끝으로 이동 |
| `Ctrl + V` | 이전 페이지로 이동 |
| `Ctrl + Y` | 다음 페이지로 이동 |
| `Ctrl + C` | 현재 커서 위치 표시 |
| `Ctrl + T` | 영문자 철자 확인 |
| `Ctrl + W` | 원하는 문자열 찾기 |
| `Ctrl + K` | 현재 라인 삭제 |
| `Ctrl + U` | 마지막으로 삭제된 라인 복구 |
| `Ctrl + L` | 화면 갱신 |

---

## 4. 연상 암기

### 저장 / 종료

```text
Ctrl + O
→ Output
→ 저장

Ctrl + X
→ eXit
→ 종료
```

### 행 이동

```text
Ctrl + A
→ 앞
→ 현재 행 맨 앞

Ctrl + E
→ End
→ 현재 행 맨 끝
```

### 삭제 / 복구

```text
Ctrl + K
→ Kill
→ 현재 라인 삭제

Ctrl + U
→ Undo
→ 삭제된 라인 복구
```

### 기타

```text
Ctrl + R
→ Read
→ 다른 파일 불러오기

Ctrl + C
→ Cursor
→ 커서 위치 표시

Ctrl + T
→ Typo
→ 철자 확인

Ctrl + W
→ Word
→ 문자열 찾기

Ctrl + L
→ Look again
→ 화면 갱신
```

---

## 5. 페이지 이동

```text
Ctrl + V
→ 이전 페이지

Ctrl + Y
→ 다음 페이지
```

이 둘은 서로 묶어서 외운다.

---

```text

R → 다른 파일 불러오기
C → 커서 위치
T → 철자 확인
W → 문자열 찾기
L → 화면 갱신

V → 이전 페이지
Y → 다음 페이지
```
