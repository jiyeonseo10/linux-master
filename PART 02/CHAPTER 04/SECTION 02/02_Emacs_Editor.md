# Emacs Editor

## 1. 파일 저장과 종료

### 파일 저장

```text
Ctrl + X → Ctrl + S
```

```text
X-S
→ Save
→ 파일 저장
```

### 종료

```text
Ctrl + X → Ctrl + C
```

```text
X-C
→ Close
→ Emacs 종료
```

---

## 2. 마크 설정과 잘라내기

마크를 설정하려면:

```text
Ctrl + Space Bar
```

선택한 영역을 잘라내려면:

```text
Ctrl + W
```

```text
Ctrl + Space Bar
→ 마크 설정

Ctrl + W
→ 잘라내기
```

---

## 3. 한 줄 삭제

```text
Ctrl + K
```

커서 뒤에 있는 한 줄이 모두 지워진다.

지워진 문자는 클립보드에 저장된다.

```text
K = Kill
→ 한 줄 삭제
```

---

## 4. 커서 이동

| 단축키 | 기능 |
|---|---|
| `Ctrl + A` | 커서를 줄의 맨 앞으로 이동 |
| `Ctrl + E` | 커서를 줄의 맨 뒤로 이동 |
| `Ctrl + N` | 커서를 한 줄 아래로 이동 |

### 연상

```text
A → 앞
E → End
N → Next
```

---

## 5. 문자열 검색

### 커서 아래쪽 검색

```text
Ctrl + S
```

커서의 아래 부분에서 문자열을 검색한다.

```text
S = Search
→ 아래쪽 검색
```

### 커서 위쪽 검색

```text
Ctrl + R
```

커서의 윗부분에서 문자열을 검색한다.

```text
R = Reverse
→ 위쪽 검색
```

---

## 6. 진행 중인 명령 종료

```text
Ctrl + G
```

진행되고 있는 명령을 끝낸다.

```text
G = 그만
→ 진행 중인 명령 종료
```

---

# 핵심 정리

```text
Ctrl + X, Ctrl + S
→ 파일 저장

Ctrl + X, Ctrl + C
→ 종료

Ctrl + Space Bar
→ 마크 설정

Ctrl + W
→ 잘라내기

Ctrl + K
→ 한 줄 삭제

Ctrl + A
→ 줄 맨 앞

Ctrl + E
→ 줄 맨 뒤

Ctrl + N
→ 한 줄 아래

Ctrl + S
→ 아래쪽 문자열 검색

Ctrl + R
→ 위쪽 문자열 검색

Ctrl + G
→ 진행 중인 명령 종료
```

## 시험 직전 암기

```text
X-S = Save
X-C = Close

K = Kill
A = 앞
E = End
N = Next

S = Search
R = Reverse
G = 그만
```
