# vi Editor

## 1. vi의 작업 모드

vi는 다음 3가지 작업 모드로 구성된다.

```text
명령 모드(Command Mode)
편집 모드(Edit Mode)
EX 명령 모드
```

### 모드 전환

```text
vi 실행
→ 명령 모드
```

명령 모드에서 다음 키를 사용하면 편집 모드로 전환된다.

```text
i, I, a, A, o, p
```

편집 모드에서 명령 모드로 돌아갈 때:

```text
ESC
```

명령 모드에서 EX 명령 모드로 전환할 때:

```text
:
```

---

## 2. 입력 모드 전환

| 키 | 기능 |
|---|---|
| `a` | 커서 뒤부터 입력 |
| `A` | 줄의 마지막에 입력 |
| `i` | 현재 문자 앞에 입력 |
| `I` | 줄의 시작 부분에 입력 |
| `o` | 현재 줄 다음 줄에 입력 |
| `p` | 커서가 있는 줄 위에 입력 |

### 연상

```text
a → after → 커서 뒤
A → 줄 마지막
i → insert → 현재 문자 앞
I → 줄 시작
```

---

## 3. 저장 및 종료

EX 명령 모드에서 사용한다.

| 명령 | 기능 |
|---|---|
| `:wq` | 버퍼를 파일에 기록하고 종료 |
| `:q!` | 버퍼 내용을 파일에 기록하지 않고 강제 종료 |
| `:q` | 버퍼와 파일 내용이 일치할 때 종료 |

### 연상

```text
:wq
→ write + quit
→ 저장하고 종료

:q!
→ 저장하지 않고 강제 종료

:q
→ 변경 내용이 없을 때 종료
```

---

## 4. 환경 설정

| 명령 | 기능 |
|---|---|
| `:set nu` | 줄 번호 표시 |
| `:set nonu` | 줄 번호 표시 해제 |

```text
nu → number
nonu → no number
```

---

## 5. 삭제

명령 모드에서 사용한다.

| 키 | 기능 |
|---|---|
| `x` | 커서가 위치한 한 문자 삭제 |
| `dd` | 한 라인 삭제 |
| `dw` | 커서 위치에서 오른쪽 한 단어 삭제 |
| `db` | 커서 위치에서 왼쪽 한 단어 삭제 |

### 연상

```text
x  → 한 문자 삭제
dd → delete line
dw → delete word
db → delete back
```

---

## 6. 복사

| 키 | 기능 |
|---|---|
| `yy` | 한 라인 복사 |
| `yw` | 커서 위치에서 오른쪽 한 단어 복사 |
| `yb` | 커서 위치에서 왼쪽 한 단어 복사 |

```text
y = yank = 복사

yy → 한 줄 복사
yw → 오른쪽 한 단어 복사
yb → 왼쪽 한 단어 복사
```

---

## 7. 붙여넣기

| 키 | 기능 |
|---|---|
| `P` | 커서 위치에서 윗줄에 붙여넣기 |
| `p` | 커서 위치에서 아랫줄에 붙여넣기 |

```text
P → 위
p → 아래
```
