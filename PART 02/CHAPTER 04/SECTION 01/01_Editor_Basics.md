# Editor Basics

## 1. 에디터의 개념

에디터(Editor)는 **파일을 작성하고 수정하는 데 사용하는 프로그램**이다.

리눅스는 **버퍼 기반의 편집기**로 파일을 수정한다.

---

## 2. 버퍼 기반 편집 방식

원래의 파일은 훼손되지 않게 남겨두고,  
해당 파일의 복사본을 만들어 임시 기억 장치에 둔다.

이 임시 기억 장치는 편집기의 **버퍼(Buffer)** 역할을 한다.

편집기를 통해 파일을 수정하면 변화된 내용은 복사된 파일에 나타난다.

```text
원본 파일
→ 복사본 생성
→ 임시 기억 장치에 저장
→ 복사본을 편집
```

---

## 3. 버퍼 기반 편집기의 장점

사용자가 잘못 편집했을 경우  
해당 내용을 기록하지 않고 종료하면 원본 파일을 보존할 수 있다.

```text
잘못 편집
→ 저장하지 않고 종료
→ 원본 파일 보존 가능
```

---

## 4. 버퍼 기반 편집기의 단점

외부적인 원인으로 편집기가 갑자기 종료되면  
변경된 내용을 모두 잃을 수 있다.

```text
갑작스러운 종료
→ 변경 내용 손실 가능
```

---

## 5. 리눅스에서 지원하는 편집기

```text
vi
emacs
pico
gedit
xedit
```

```text
Editor
→ 파일 작성 및 수정

리눅스
→ 버퍼 기반 편집 방식

장점
→ 저장하지 않고 종료하면 원본 파일 보존 가능

단점
→ 갑작스러운 종료 시 변경 내용 손실 가능

대표 편집기
→ vi, emacs, pico, gedit, xedit
```
