# DPKG Package Management

## 1. dpkg

`dpkg`는 **데비안의 저수준(Low-level) 패키지 관리 도구**이다.

주요 기능:

- `.deb` 패키지 설치
- 패키지 삭제
- 패키지 정보 확인
- 루트 권한으로 설치 및 삭제 가능
- 패키지 설치 및 제거 시 RPM과 같은 의존성 문제가 발생할 수 있음

```text
dpkg
→ Debian 계열
→ Low-level 패키지 관리 도구
→ .deb 패키지 사용
```

---

## 2. deb 패키지 파일

데비안 패키지 파일의 확장자는 다음과 같다.

```text
.deb
```

파일명 구성:

```text
패키지명_버전-릴리즈번호-리비전_아키텍처.deb
```

### 구성 요소

| 항목 | 의미 |
|---|---|
| 패키지명 | 패키지의 속성을 나타내는 파일명 |
| 버전 | 패키지 버전 |
| 릴리즈번호 | 해당 버전의 문제점을 개선할 때마다 붙는 번호 |
| 리비전 | 보안 문제, 의존성 변화, 스크립트 변화 등이 있음을 의미 |
| 아키텍처 | 시스템 아키텍처 정보 |

아키텍처가 `all`이면 시스템과 상관없는 문서나 스크립트 등을 의미한다.

---

## 3. dpkg 기본 형식

```bash
dpkg [옵션] 패키지명.deb
```

---

## 4. dpkg 주요 옵션

| 옵션 | 기능 |
|---|---|
| `-i` | 패키지 설치 |
| `-r` | 설치된 패키지만 삭제 |
| `-P` | 패키지와 설정 정보 모두 삭제 |
| `-s` | 패키지 상태 정보 출력 |
| `-L` | dpkg가 설치한 모든 파일 목록 확인 |

---

## 5. 옵션 연상 암기

```text
-i
→ install
→ 설치

-r
→ remove
→ 패키지만 삭제

-P
→ Purge
→ 패키지 + 설정 정보 삭제

-s
→ status
→ 상태 정보

-L
→ List
→ 설치 파일 목록
```

---

## 6. -r 과 -P 차이

```text
-r
→ 패키지만 삭제
→ 설정 정보는 남김

-P
→ 패키지 + 설정 정보 모두 삭제
```

시험에서는 이 차이를 꼭 구분한다.

---

## 7. 패키지 정보 확인

예:

```bash
dpkg -s gcc
```

지정한 패키지에 대한 자세한 정보를 출력한다.

확인 가능한 정보 예:

```text
패키지 상태
버전
관리자
아키텍처
```

# 핵심 정리

```text
dpkg
→ Debian 계열
→ Low-level 패키지 관리 도구
→ .deb 사용
→ 의존성 문제 발생 가능
```

```text
-i → install → 설치
-r → remove → 패키지만 삭제
-P → purge → 패키지 + 설정 삭제
-s → status → 상태 정보
-L → list → 설치 파일 목록
```

```text
-r = 패키지만 삭제
-P = 패키지 + 설정까지 삭제
```
