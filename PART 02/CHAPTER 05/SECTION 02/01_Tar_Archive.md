# File Archive - tar

## 1. 파일 아카이브

아카이브(Archive)는 **여러 개의 파일이나 디렉토리를 하나의 파일로 묶는 것**이다.

주요 용도:

```text
여러 파일을 한 번에 전송
파일 백업
```

---

## 2. tar

`tar`는 파일이나 디렉토리를 하나의 아카이브 파일로 묶거나 해제할 때 사용한다.

형식:

```bash
tar [옵션] 파일명
```

---

## 3. 주요 옵션

| 옵션 | 기능 |
|---|---|
| `c` | 새로운 아카이브 파일 생성 |
| `x` | tar로 묶은 파일을 원본 파일로 복원 |
| `d` | 아카이브에 있는 파일과 비교 |
| `r` | 아카이브된 파일의 마지막 부분에 파일 추가 |
| `t` | 아카이브 파일 안의 파일 목록 나열 |
| `u` | 기존 파일보다 새로운 파일로 업데이트 |
| `f` | 아카이브 파일명 지정 |
| `v` | 처리 중인 파일 정보 출력 |
| `z` | gzip으로 압축하거나 해제 |
| `j` | bzip2로 압축하거나 해제 |
| `P` | 절대 경로 정보 유지 |
| `J` | xz 압축 파일에 사용 |
| `--exclude` | 특정 디렉토리를 제외하고 묶음 |

---

## 4. 기본 옵션 연상 암기

```text
c → create
→ 새로운 아카이브 생성

x → extract
→ 아카이브 해제

t → 목록 확인

f → file
→ 아카이브 파일명 지정

v → verbose
→ 처리 정보 출력
```

---

## 5. 압축 관련 옵션

```text
z → gzip
j → bzip2
J → xz
```

확장자와 같이 기억:

```text
.tar.gz  → z
.tar.bz2 → j
.tar.xz  → J
```

대소문자 주의:

```text
j → bzip2
J → xz
```
