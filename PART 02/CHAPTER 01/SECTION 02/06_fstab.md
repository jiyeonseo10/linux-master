# /etc/fstab

`/etc/fstab`은 리눅스에서 사용하는 **파일 시스템 정보를 정적으로 저장하는 설정 파일**이다.

주요 역할:
- 파일 시스템 정보 저장
- 부팅 시 마운트 정보 저장
- 어떤 파티션을 어디에 자동 마운트할지 설정
- 마운트 옵션 지정
- dump 관련 설정
- 부팅 시 fsck 점검 순서 지정

---

## 1. /etc/fstab의 6개 필드

예:

```text
proc /proc proc defaults 0 0
```

각 필드는 다음과 같다.

| 순서 | 필드 | 의미 |
|---|---|---|
| 1 | 파일 시스템 장치명 | 장치명, 볼륨라벨, UUID |
| 2 | 마운트 포인트 | 파일 시스템이 마운트될 위치 |
| 3 | 파일 시스템 종류 | ext4, proc, swap 등 |
| 4 | 옵션 | 파일 시스템 속성 설정 |
| 5 | dump 관련 설정 | 백업 주기 설정 |
| 6 | 파일 점검 옵션 | 부팅 시 fsck 점검 순서 |

```text
1 → 장치명
2 → 마운트 포인트
3 → 파일 시스템 종류
4 → 옵션
5 → dump
6 → fsck 순서
```

---

## 2. 파일 시스템 옵션

### defaults

기본적인 파일 시스템 속성을 사용한다.

책에서는 다음과 같은 속성을 가지는 것으로 설명한다.

```text
auto, exec, suid, ro, rw 등
```

### auto

부팅 시 자동 마운트한다.

### exec

실행 파일의 실행을 허용한다.

### suid

SetUID와 SetGID의 사용을 허용한다.

### ro

읽기 전용으로 설정한다.

```text
ro → Read Only
```

### rw

읽기와 쓰기를 허용한다.

```text
rw → Read / Write
```

### user

일반 사용자에게 마운트 권한을 부여한다.

### usrquota

사용자별 디스크 쿼터를 설정한다.

### grpquota

그룹별 디스크 쿼터를 설정한다.

---

## 3. 비활성화 옵션

| 옵션 | 의미 |
|---|---|
| `noauto` | 부팅 시 자동 마운트 비활성화 |
| `noexec` | 실행 파일 실행 허용 비활성화 |
| `nosuid` | SetUID / SetGID 사용 비활성화 |
| `nouser` | 일반 사용자의 마운트 권한 부여 금지 |

---

## 4. dump 관련 설정

dump 명령을 이용하여 백업할 때의 덤프 레벨을 설정한다.

| 값 | 의미 |
|---|---|
| `0` | 덤프 불가 |
| `1` | 매일 데이터 백업 가능 |
| `2` | 이틀에 한 번 데이터 백업 가능 |

---

## 5. fsck 파일 점검 순서

부팅 시 파일 시스템을 검사하는 순서를 지정한다.

| 값 | 의미 |
|---|---|
| `0` | 부팅 시 파일 시스템을 점검하지 않음 |
| `1` | 루트 파일 시스템 점검 |
| `2` | 루트 파일 시스템 이외의 파일 시스템 점검 |

```text
0 → 점검 X
1 → root
2 → root 이외
```

---

## 6. 예제 해석

```text
proc /proc proc defaults 0 0
```

해석:

```text
proc
→ 파일 시스템 장치명

/proc
→ 마운트 포인트

proc
→ 파일 시스템 종류

defaults
→ 기본 옵션 사용

0
→ dump 사용 안 함

0
→ 부팅 시 fsck 점검 안 함
```

---

## 핵심 정리

```text
/etc/fstab
→ 파일 시스템 및 부팅 시 마운트 설정 파일
```

6개 필드:

```text
장치명
→ 마운트 포인트
→ 파일 시스템 종류
→ 옵션
→ dump
→ fsck
```

주요 옵션:

```text
auto     → 자동 마운트
exec     → 실행 허용
suid     → SetUID/SetGID 허용
ro       → 읽기 전용
rw       → 읽기/쓰기
user     → 일반 사용자 마운트 허용
usrquota → 사용자 디스크 쿼터
grpquota → 그룹 디스크 쿼터
```

반대 옵션:

```text
noauto
noexec
nosuid
nouser
```

fsck 순서:

```text
0 → 점검하지 않음
1 → 루트 파일 시스템
2 → 루트 이외 파일 시스템
```
