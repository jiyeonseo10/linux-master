# Shell Variables

## 1. 환경 변수와 셸 변수

### 환경 변수

환경 변수는 **전역 변수**로, 서브 셸에 상속될 수 있다.

확인 명령어:

```bash
env
```

```text
환경 변수
→ 전역 변수
→ 서브 셸에 상속 가능
→ env로 확인
```

### 셸 변수

셸 변수는 **지역 변수**로, 현재 셸에서 사용한다.

확인 명령어:

```bash
set
```

```text
셸 변수
→ 지역 변수
→ 서브 셸에 상속되지 않음
→ set으로 확인
```

---

## 2. 주요 환경 변수

| 변수 | 의미 |
|---|---|
| `PATH` | 명령어 검색 경로 |
| `HOME` | 사용자의 홈 디렉토리 절대 경로 |
| `HOSTNAME` | 호스트 이름 |
| `USER` | 사용자 이름 |
| `DISPLAY` | X 서버 주소 지정 |
| `PS1` | 기본 셸 프롬프트 |
| `PS2` | 2차 셸 프롬프트 |
| `PWD` | 현재 디렉토리의 절대 경로 |
| `SHELL` | 로그인 셸의 절대 경로 |
| `TERM` | 터미널 종류 |
| `TMOUT` | 로그아웃 관련 시간 제어 |
| `LANG` | 기본 지원 언어 |
| `PRINT` | 기본 프린터 |
| `MAIL` | 도착한 메일이 저장되는 경로 |

### 핵심

```text
PATH  → 명령어 검색 경로
HOME  → 홈 디렉토리
PWD   → 현재 디렉토리
SHELL → 로그인 셸
PS1   → 기본 프롬프트
PS2   → 2차 프롬프트
LANG  → 기본 언어
```

---

## 3. 환경 변수 설정

### 환경 변수 목록 확인

```bash
export
```

### 환경 변수 등록

```bash
export 변수명=변수값
```

예:

```bash
export YJ=YoungJin
```

또는 먼저 변수를 만든 뒤:

```bash
YJ=YoungJin
export YJ
```

---

## 4. 환경 변수 값 확인

```bash
echo $변수명
```

예:

```bash
echo $YJ
```

---

## 5. 변수 해제

```bash
unset 변수명
```

예:

```bash
unset YJ
```

```text
export → 환경 변수 설정
echo $변수명 → 변수 값 확인
unset → 변수 해제
```

---

## 6. PATH에 새로운 경로 추가

현재 PATH 확인:

```bash
echo $PATH
```

기존 PATH에 새로운 경로 추가:

```bash
export PATH=$PATH:/TST/bin
```

기존 PATH와 추가 경로는 **콜론(`:`)**으로 구분한다.

```text
$PATH:추가경로
```

---

## 7. 프롬프트 설정 형식

| 형식 | 의미 |
|---|---|
| `\t` | 24시간제 현재 시간 |
| `\W` | 현재 작업 디렉토리의 마지막 디렉토리명 |
| `\w` | 현재 작업 디렉토리의 절대 경로 |
| `\s` | 사용 중인 셸 이름 |
| `\u` | 현재 사용자 이름 |
| `\h` | 호스트 이름 |

### 주의

```text
\W → 마지막 디렉토리명
\w → 전체 절대 경로
```
