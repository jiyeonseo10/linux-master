# BSD Printer Commands

## 1. BSD 계열 프린터 명령어

책에 나온 BSD 계열 프린터 명령어는 다음과 같다.

```text
lpr
lpq
lprm
lpc
```

```text
lpr  → 프린터 작업 요청
lpq  → 프린터 큐 작업 목록 출력
lprm → 프린터 작업 삭제
lpc  → 프린터 / 프린터 큐 제어
```

---

## 2. lpr

`lpr`은 **프린터 작업을 요청**하는 명령어이다.

형식:

```bash
lpr [옵션] [파일명]
```

### 주요 옵션

| 옵션 | 기능 |
|---|---|
| `-# 값` | 인쇄할 매수 지정(1~100) |
| `-m` | 작업 완료 시 관련 정보를 E-mail로 전송 |
| `-P 프린터명` | 기본 프린터 이외의 다른 프린터 지정 |
| `-r` | 출력 후 지정한 파일 삭제 |

### 연상

```text
m → mail
P → Printer
r → remove
```

---

## 3. lpq

`lpq`는 **프린터 큐에 있는 작업 목록을 출력**하는 명령어이다.

형식:

```bash
lpq [옵션]
```

### 주요 옵션

| 옵션 | 기능 |
|---|---|
| `-a` | 설정된 모든 프린터의 작업 정보 출력 |
| `-l` | 출력 결과를 자세히 출력 |
| `-P 프린터명` | 특정 프린터 지정 |

### 핵심

```text
q = queue

lpq
→ 프린터 큐 확인
```

---

## 4. lprm

`lprm`은 **프린터 큐에 대기 중인 작업을 삭제**하는 명령어이다.

취소할 프린트 작업 번호를 입력한다.

작업번호가 명시되지 않은 경우 가장 마지막에 요청한 작업이 취소된다.

### 주요 옵션

| 옵션 | 기능 |
|---|---|
| `-` | 프린터 큐에 있는 모든 작업 취소 |
| `-U 사용자명` | 지정한 사용자의 인쇄 작업 취소 |
| `-P 프린터명` | 특정 프린터 지정 |
| `-h 서버` | 지정한 서버의 인쇄 작업 취소 |

### 연상

```text
rm = remove

lprm
→ 인쇄 작업 삭제
```

---

## 5. lpc

`lpc`는 **라인 프린터 컨트롤 프로그램**이다.

주요 기능:

```text
프린터 제어
프린터 큐 제어
```

### 연상

```text
c = control

lpc
→ 프린터 / 프린터 큐 제어
```

---

# 핵심 정리

```text
lpr
→ 인쇄 요청

lpq
→ 큐 조회

lprm
→ 인쇄 작업 삭제

lpc
→ 프린터 / 큐 제어
```

```text
lpr -P
→ 특정 프린터 지정

lpr -r
→ 출력 후 파일 삭제

lpq -l
→ 자세한 결과 출력

lprm -U
→ 특정 사용자의 인쇄 작업 취소
```

## 시험 직전 암기

```text
r  = request
q  = queue
rm = remove
c  = control
```
