# X Window Basics

## 1. X-윈도우의 개념

X-윈도우는 **플랫폼과 독립적으로 동작하는 그래픽 시스템**이다.

리눅스 환경의 여러 애플리케이션과 유틸리티에 대해  
그래픽 사용자 인터페이스(GUI)를 제공한다.

다음과 같이도 부른다.

```text
X11
X
X Window System
```

### 핵심

```text
X-윈도우
→ 플랫폼 독립적 그래픽 시스템
→ GUI 제공
```

---

## 2. X-윈도우의 역사

책에 나온 흐름:

```text
Athena 프로젝트
→ X 컨소시엄
→ 오픈 그룹
→ X.org
```

### Athena 프로젝트

- IBM, MIT, DEC의 Athena 프로젝트
- Bob Scheifler와 Jim Gettys가 1984년에 X-윈도우를 처음 개발
- 1987년 X11 발표

### X 컨소시엄

- 1988년 여러 컴퓨터 제조업체로 구성
- X11 버전을 개정
- X11R6.3을 끝으로 컨소시엄 해체

### 오픈 그룹

- 1996년 x/open으로 형성된 그룹
- X11R6.4 발표

### X.org

- 오픈 그룹을 기반으로 2004년에 X.org 재단이 만들어짐
- 2004년 9월 X11R6.8 발표

---

## 3. X-윈도우의 특징

책에 나온 주요 특징:

```text
네트워크 기반 그래픽 환경 지원
다른 기종의 시스템에서도 사용 가능
디스플레이 장치에 종속적이지 않음
원하는 인터페이스 구성 가능
클라이언트 / 서버 구조
```

---

## 4. X 프로토콜

X-윈도우는 **X 프로토콜 기반의 클라이언트/서버 시스템**이다.

```text
X-윈도우
→ X 프로토콜
→ Client / Server 구조
```

---

## 5. X Server

X 서버는 다음 역할을 담당한다.

- 클라이언트의 디스플레이 접근 허용
- 클라이언트 간 자원 공유
- 네트워크 메시지 전달
- 클라이언트와 입출력 기기 사이의 중계

### 핵심

```text
X Server
→ 디스플레이 및 입출력 자원 관리
```

---

## 6. X Client

X 클라이언트는 **애플리케이션**이다.

X 서버가 제공하는 기능을 이용한다.

```text
X Client
→ 애플리케이션
```
