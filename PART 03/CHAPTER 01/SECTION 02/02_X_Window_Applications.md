# X Window Applications

## 1. 오피스 프로그램

### LibreOffice

`LibreOffice`는 오피스 프로그램 패키지이다.

```text
Writer
→ 문서 작성기

Impress
→ 프레젠테이션

Calc
→ 스프레드시트

Draw
→ 드로잉 프로그램
```

### gedit

```text
gedit
→ 텍스트 편집 프로그램
```

### kwrite

```text
kwrite
→ KDE 기반 텍스트 편집기
```

---

## 2. 그래픽 프로그램

### GIMP

```text
GIMP
→ 이미지 편집 프로그램
```

### ImageMagick

이미지 생성 및 편집을 지원한다.

지원 포맷 예:

```text
bitmap
gif
jpeg
png
```

### eog

```text
eog
→ GNOME의 이미지 뷰어
```

### kolourpaint

```text
kolourpaint
→ Ubuntu 이미지 편집 프로그램
```

### gThumb

```text
gThumb
→ GNOME 데스크톱 이미지 뷰어
→ JPEG / GIF / TIF / PNG 등 지원
→ 간단한 이미지 편집 가능
```

### gwenview

```text
gwenview
→ KDE의 기본 이미지 뷰어
→ zip, rar 압축 파일도 볼 수 있음
```

---

## 3. 멀티미디어 프로그램

### Totem

```text
Totem
→ GNOME 기반 사운드 및 비디오 재생 프로그램
```

### RHYTHMBOX

```text
RHYTHMBOX
→ 통합형 음악 관리 프로그램
```

### CHEESE

```text
CHEESE
→ GNOME 기반 카메라 동영상 프로그램
```

---

## 4. 개발 프로그램

### Eclipse

`Eclipse`는 통합 개발 환경이다.

주요 특징:

```text
자바를 비롯한 다양한 언어 지원
OSGi를 이용한 범용 응용 소프트웨어 플랫폼으로 발전
```

```text
Eclipse
→ 통합 개발 환경
```

---

## 5. 기타 프로그램

### Dolphin

`Dolphin`은 KDE용 파일 관리자이다.

주요 기능:

```text
이동 경로 표시
파일 미리보기
실행 취소 / 재실행
```

### KSnapshot

```text
KSnapshot
→ 스크린샷 프로그램
```
