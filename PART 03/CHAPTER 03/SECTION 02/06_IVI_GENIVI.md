# IVI & GENIVI

## 1. IVI 정의

`IVI`는 **In-Vehicle Infotainment**의 약자이다.

`Infotainment`는 다음 두 단어의 합성어이다.

```text
Information
+
Entertainment
```

즉, 정보 전달에 오락성을 더한 차량 내부 시스템이다.

### 핵심

```text
IVI
→ In-Vehicle Infotainment
→ Information + Entertainment
```

---

## 2. IVI의 주요 구성

책에 나온 차량 내부 시스템:

```text
내비게이션
계기판(Instrument Cluster)
트립 컴퓨터
AV 시스템
DMB
MP3
오디오
외부 기기 연결
```

### 핵심

```text
IVI
→ 차량 내부의 정보 / 오락 기능 통합
```

---

## 3. 최신 IVI 기능

책에 나온 기능:

```text
차량 관련 정보
정기점검 안내
운전자 음성인식
도난 방지 경보
```

즉 단순한 오락 기능뿐 아니라 운전자 편의성과 안전 관련 기능도 포함한다.

---

## 4. IVI의 특징

책에 나온 특징:

```text
GENIVI 표준 플랫폼 기반

운전자 편의성 및 안전성 증대

소프트웨어 품질관리 프로세스를 통한 품질 확보

CE4A 표준 터미널 모드와 확장 API 기술을 포함한
스마트폰 연동 기술 탑재

AUTOSAR 연계 소프트웨어 진단(DLT) 서비스 기술 탑재
```

### 핵심

```text
IVI
→ GENIVI
→ 편의성 / 안전성
→ 스마트폰 연동
```

---

# GENIVI

## 5. GENIVI 정의

`GENIVI`는 **GENEVA In-Vehicle Infotainment**이다.

책에서는 GENIVI를:

```text
오픈 소스 기반 플랫폼 얼라이언스
```

라고 설명한다.

주요 목적:

```text
오픈 소스 기반
차량 멀티미디어 플랫폼 표준화
```

BMW 등 유럽·북미 자동차 OEM과 자동차 부품업체를 중심으로 구성된 자동차 산업 표준 협의체이다.

### 핵심

```text
GENIVI
→ Open Source 기반
→ 차량 멀티미디어 플랫폼 표준화
```

---

## 6. GENIVI와 오픈 소스

GENIVI SW 플랫폼은 기존 오픈 소스 기술을 많이 활용한다.

책에 나온 주요 기반:

```text
Linux OS
Open Source Components
```

---

# GENIVI 80 / 15 / 5 구조

## 7. 80%

GENIVI SW 플랫폼 기본 구조의 약 80%는 기존 오픈 소스로 구성된다.

```text
80%
→ 기존 Open Source
→ Linux OS + Open Source Components
```

---

## 8. 15%

약 15%는 기존 오픈 소스를 차량용으로 사용하기 위해 일부 수정하거나 최적화한다.

```text
15%
→ 차량용 수정
→ 차량용 최적화
```

---

## 9. 5%

나머지 약 5%는 새로운 차량용 기술을 반영하기 위한 신규 코드이다.

```text
5%
→ 새로운 차량용 기술
→ 신규 코드 추가
```
