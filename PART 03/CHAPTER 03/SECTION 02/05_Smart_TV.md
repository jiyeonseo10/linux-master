# Smart TV

## 1. 스마트 TV 정의

스마트 TV는 텔레비전에 인터넷 접속 기능이 결합되어  
각종 애플리케이션을 설치하고 다양한 기능을 사용할 수 있는 다기능 TV이다.

```text
Smart TV
→ TV + 인터넷
→ 애플리케이션 설치
→ 다양한 기능 사용
```

TV 방송 시청 이외에도 다양한 기능을 활용할 수 있다.

또한 TV, 휴대폰, PC의 3개 스크린을 자유롭게 넘나들며  
데이터의 끊김 없이 동영상을 볼 수 있다.

```text
3 Screen
→ TV
→ 휴대폰
→ PC
```

스마트 TV는 다음과 같이 부르기도 한다.

```text
Internet TV
Connected TV
```

---

## 2. 스마트 TV의 기능

책에 나온 기능:

```text
인터넷에서 콘텐츠 실시간 다운로드
뉴스 확인
날씨 확인
이메일 확인
```

즉 커뮤니케이션 센터의 역할도 수행한다.

# 스마트 TV 운영체제

## 3. Tizen

Tizen은 휴대전화를 비롯하여 TV, 냉장고 등  
모든 전자기기에 포함하는 것을 목표로 하는 오픈 소스 모바일 운영체제이다.

책에 나온 특징:

```text
Linux Kernel 기반
HTML5
C++
```

소프트웨어 개발 키트(SDK)를 통해 응용 프로그램 개발에 필요한  
각종 도구와 API를 제공한다.

### 핵심

```text
Tizen
→ Linux Kernel
→ HTML5 + C++
→ SDK / API 제공
```

---

## 4. Tizen 개발 및 TV 적용

책 표 기준:

```text
2012년 1월
→ 삼성전자, Intel, Panasonic 등이 공동개발

2015년 1월
→ TV 적용
```

특징:

```text
다양한 가전제품 연결
→ 사물 인터넷(IoT)에 강점
```

주기업:

```text
삼성전자
```

### 핵심

```text
Tizen
→ Samsung
→ IoT
→ TV 적용 2015
```

# webOS

## 5. webOS

webOS는 Linux Kernel에서 구동되는 모바일 운영체제이다.

책에 나온 흐름:

```text
2009년 1월
→ Palm 개발

2012년
→ HP 인수

2013년
→ LG전자 인수
```

### 암기

```text
Palm
→ HP
→ LG
```

---

## 6. webOS 스마트 TV

책에서는 2014년 CES에서 webOS가 내장된 스마트 TV를 선보였다고 설명한다.

LG의 webOS 스마트 TV는 기존 webOS의 특징인:

```text
Card View
```

를 계승하였다.

책 표 기준:

```text
TV 적용
→ 2014년 1월

특징
→ 멀티태스킹이 편리

주기업
→ LG전자
```

### 핵심

```text
webOS
→ LG
→ Card View
→ 멀티태스킹
→ TV 적용 2014
```

# Tizen vs webOS

| 구분 | Tizen | webOS |
|---|---|---|
| 기반 | Linux Kernel | Linux Kernel |
| 주요 기업 | 삼성전자 | LG전자 |
| TV 적용 | 2015년 1월 | 2014년 1월 |
| 특징 | IoT에 강점 | 멀티태스킹 편리 |
| 추가 특징 | HTML5 + C++ | Card View |
