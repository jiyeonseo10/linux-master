# Mobile OS

## 1. 모바일 운영체제 정의

스마트폰의 OS는 메모리, LCD, CPU 등 하드웨어 부품을 효율적으로 관리하고 구동하며  
사용자와 편리하게 의사소통할 수 있도록 만든 소프트웨어 플랫폼이다.

적용 대상:

```text
스마트폰
태블릿 컴퓨터
PDA
```

대표적인 모바일 OS:

```text
Android
iOS
```

---

# 리눅스 기반 공개형 운영체제

## 2. Maemo

책 기준 특징:

```text
2005년 11월
→ Nokia가 스마트폰 및 인터넷 태블릿용으로 만든 소프트웨어 플랫폼

Linux 기반

2010년 2월
→ Intel의 Moblin과 합병
→ MeeGo 프로젝트로 변경
```

### 핵심

```text
Maemo
→ Nokia
→ Linux 기반
→ Moblin과 합병
→ MeeGo
```

---

## 3. Moblin

`Moblin`은 Mobile Linux의 약어이다.

책 기준:

```text
2007년 7월
→ Intel과 Linux Foundation이 개발

오픈 소스 운영체제

MID
Netbook
등의 임베디드 모바일 기기용

2010년 2월
→ Nokia의 Maemo와 합병
→ MeeGo
```

### 핵심

```text
Moblin
→ Mobile Linux
→ Intel
→ Maemo와 합병
→ MeeGo
```

---

## 4. MeeGo

MeeGo는 다음 두 프로젝트가 합쳐져 만들어졌다.

```text
Intel Moblin
+
Nokia Maemo
```

```text
Moblin + Maemo
→ MeeGo
```

책에 나온 적용 분야:

```text
넷북
스마트폰
태블릿
IVI
차량용 내비게이션
스마트 TV
```

---

## 5. LiMo

`LiMo`는 Linux Mobile의 약자이다.

책 기준:

```text
2007년 1월
→ 삼성전자, NEC, Panasonic, Vodafone 등이 참여

2011년 9월
→ 프로젝트 종료
→ MeeGo로 대체

2012년
→ Intel과 삼성전자 중심으로 Tizen 프로젝트 시작
```

### 핵심

```text
LiMo
→ Linux Mobile
→ 삼성전자 등 참여
→ 이후 Tizen 프로젝트로 연결
```

---

## 6. Tizen

책에서는 Intel과 Samsung을 중심으로 만든  
Linux 기반 무료 공개형 모바일 운영체제로 설명한다.

특징:

```text
Intel + Samsung 중심

Linux Foundation
MeeGo 개발자 등 참여

Linux 기반

2012년 1월 SDK 발표

2012년 4월
→ Version 1.0 발표
→ 코드명 Larkspur

웹 표준과 HTML5 지원
```

적용 목표:

```text
태블릿
넷북
스마트폰
스마트 TV
IVI
```

### 핵심

```text
Tizen
→ Intel + Samsung
→ Linux 기반
→ HTML5 지원
```

# iOS

## 7. iOS

책 기준:

```text
Apple에서 개발

iPhone에 적용된 Apple 제품 전용 운영체제

2008년 6월 이후
→ iOS 소프트웨어 개발 SDK 공개

2.0 버전부터
→ Apple App Store를 통해
   응용 프로그램 공개 및 판매 가능
```

### 핵심

```text
iOS
→ Apple
→ iPhone
→ SDK
→ App Store
```

# Android

## 8. Android

책 기준:

```text
Google에서 만든 스마트폰용 운영체제

2005년
→ Google이 Andy Rubin이 설립한 Android 회사를 인수

2007년 11월
→ Android 플랫폼 무료 공개 발표

Linux Kernel 2.6 기반

Java 사용
```

### 핵심

```text
Android
→ Google
→ Linux Kernel 2.6
→ Java
→ 무료 공개
```
