# Linux Trends

## 1. 리눅스의 초기와 활용 분야

1991년 초기 리눅스는 주로 **서버**로 이용되었다.

현재 리눅스 활용 분야는 크게 다음과 같이 나눌 수 있다.

```text
서버
데스크톱 및 개발
임베디드
```

---

## 2. 서버 분야

리눅스는 유닉스 시장을 대체하는 강력한 운영체제로 대두되었다.

```text
Linux
→ 서버 분야
→ UNIX 시장을 대체하는 운영체제로 발전
```

---

## 3. 데스크톱 및 개발 분야

책에 나온 주요 활용 분야:

```text
리눅스 기반 모바일 운영체제
클러스터링 서비스
온라인 게임 서비스
고성능 컴퓨팅 환경
Hadoop
분산 파일 시스템
빅데이터 분석
```

### 핵심

```text
데스크톱 / 개발
→ 모바일
→ 클러스터링
→ 온라인 게임
→ Hadoop
→ 빅데이터
```

---

## 4. 임베디드 분야

책에 나온 활용 예:

```text
스마트폰
Tablet
스마트 TV
IVI(In-Vehicle Infotainment)
가전기기
```

### 핵심

```text
Embedded
→ 스마트폰
→ Tablet
→ 스마트 TV
→ IVI
→ 가전기기
```

---

# 리눅스 시장 동향

## 5. 시장 동향

책에서는 다음과 같이 설명한다.

```text
리눅스 탑재 운영체제 판매
→ 증가

유상 리눅스 운영체제 서버 판매
→ 감소 추세
```

---

# 리눅스의 표준화

## 6. 국제 표준

리눅스는 기본적으로 다음과 같은 국제 표준을 따른다.

```text
POSIX 표준
인터넷 프로토콜 표준
```

리눅스는 오픈 소스라는 특성 때문에 국제 표준을 잘 반영한 운영체제이다.

### 핵심

```text
Linux
→ POSIX
→ 인터넷 프로토콜 표준
→ 국제 표준
```

---

# 리눅스의 법적 지위

## 7. 저작권

리눅스는 저작권법상 컴퓨터 프로그램으로서  
**저작권법의 보호 대상**이다.

```text
Linux
→ 저작권 보호 대상
```

---

## 8. 특허

책에서는 다음과 같이 설명한다.

```text
리눅스 커널
→ 특허 대상이 될 수 있음
```

---

## 9. 상표

책에서는:

```text
'리눅스'라는 용어 자체
→ 상표 등록 불가능
```

이라고 설명한다.

하지만:

```text
다른 용어 추가
또는
적용 분야를 달리함

→ 상표 등록 가능
```

---

## 10. 영업 비밀

소스코드가 공개되어 있더라도 이를 가져다가 새로운 소프트웨어를 개발하고  
기업에서 영업 비밀로 관리하면 관련 법률에 의해 보호될 수 있다.
