# Embedded System

## 1. 임베디드 시스템 정의

임베디드 시스템은 하드웨어와 소프트웨어가 결합되어  
**특정한 목적을 수행하는 시스템**이다.

미리 정해진 특정 기능을 수행하는 프로그램이 내장되어 있다.

```text
Embedded System
→ H/W + S/W
→ 특정 목적 수행
→ 특정 기능 내장
```

활용 분야:

```text
휴대 정보 단말
지리 정보 시스템
의료 정보 단말
정보가전
게임기기
자동차
항공기 / 우주선
의료 및 산업 원격 조종 장비
```

---

# 시스템 구성 요소

## 2. 하드웨어

책에 나온 하드웨어 구성요소:

```text
프로세서 / 컨트롤러
메모리
I/O 장치
네트워크 장치
센서
구동기
```

마이크로 프로세서나 마이크로 컨트롤러 등을 내장하여 특정 기능을 수행한다.

---

## 3. 소프트웨어

책에 나온 소프트웨어 구성:

```text
운영체제
시스템 S/W
응용 S/W
```

구조:

```text
H/W
→ Micro Processor
→ Memory
→ 입출력 장치
→ 네트워크 장치

S/W
→ OS-Kernel
→ 시스템 소프트웨어
→ 응용 소프트웨어
```

# 임베디드 리눅스 장점

## 5. 장점

### 기능성과 확장성

```text
기능성 우수
확장성 우수
```

### 다양한 CPU Platform 지원

책에 나온 예:

```text
PowerPC
ARM
MIPS
```

### 가격 경쟁력

```text
로열티 없음
→ 가격 경쟁력 우수
```

### 넓은 사용자층

```text
사용자층이 넓음
→ 오류 수정이 빠름
→ 안정성 우수
```

### 개발 용이

```text
기존 데스크톱 개발 환경과 동일
→ 개발 용이
```

# 임베디드 리눅스 단점

## 6. 단점

### 많은 메모리 요구

```text
기존 RTOS보다
→ 많은 메모리 요구
```

### Text 기반 개발 환경

```text
개발 환경이 Text 기반
→ 개발에 어려움
```

### GUI 개발

```text
GUI 환경 개발 어려움
```

### 메모리 접근

```text
사용자모드 / 커널모드
메모리 접근이 복잡

→ 제품화를 위한 솔루션 구성 어려움
```

### 표준화

```text
여러 업체와 개발자가 독자적으로 개발
→ 표준화 어려움
```

## 시험 직전 암기

```text
임베디드
= 특정 목적
= H/W + S/W
```

```text
특징 4개

특정 목적
실시간
높은 신뢰성
소형·경량·저전력
```

```text
장점
→ 확장성 / 다양한 CPU / 로열티 X

단점
→ 메모리 많이 필요 / GUI 어려움 / 표준화 어려움
```
