# Router, Gateway & UTP Cabling

## 1. Router

라우터(Router)는 **서로 다른 네트워크를 연결하고 목적지까지 최적의 경로를 설정하여 데이터를 전달하는 장비**이다.

책에서는 OSI 모델의 다음 계층 기능을 지원한다고 설명한다.

```text
물리 계층
데이터링크 계층
네트워크 계층
```

주요 역할:

```text
서로 다른 통신망 연결
서로 다른 프로토콜을 사용하는 네트워크 간 통신
LAN 연결
최적 경로 설정
목적지까지 데이터 전달
```

### 핵심

```text
Router
→ 서로 다른 네트워크 연결
→ 최적 경로 설정
→ 데이터 전달
```

---

## 2. Gateway

게이트웨이(Gateway)는 **서로 다른 형태의 네트워크를 상호 접속하는 장비**이다.

주요 특징:

- 서로 다른 통신망 사이의 통신 가능
- 서로 다른 프로토콜을 사용하는 네트워크 간 통신 가능
- 서로 다른 데이터 포맷 사이에서 중개자 역할 수행

### 핵심

```text
Gateway
→ 서로 다른 통신망 연결
→ 서로 다른 프로토콜 중개
→ 데이터 포맷 중개
```

---

## 3. Router와 Gateway 비교

```text
Router
→ 최적 경로를 결정
→ 데이터를 목적지까지 전달

Gateway
→ 서로 다른 시스템이나 프로토콜 사이를 중개
```

### 시험용 암기

```text
Router = Route = 경로

Gateway = Gate = 서로 다른 네트워크 사이의 관문
```

# UTP Cabling

## 4. 다이렉트 케이블

다이렉트 케이블은 **양쪽 커넥터의 배열이 같은 케이블**이다.

책에서는 양쪽 모두 다음 규격을 사용한다.

```text
EIA/TIA 568-B ↔ EIA/TIA 568-B
```

### 사용

책 기준으로 서로 다른 기종의 장비를 연결할 때 사용한다.

```text
컴퓨터 ↔ 허브
컴퓨터 ↔ 스위치
라우터 ↔ 허브/스위치
```

### 핵심

```text
Direct Cable
→ B ↔ B
→ 같은 배열
→ 다른 기종 연결
```

---

## 5. 크로스오버 케이블

크로스오버 케이블은 한쪽은 `568-B`, 다른 한쪽은 `568-A`로 연결한다.

```text
EIA/TIA 568-B ↔ EIA/TIA 568-A
```

책에서는 같은 기종의 장비를 연결할 때 사용한다고 설명한다.

예:

```text
컴퓨터 ↔ 컴퓨터
스위치 ↔ 스위치
컴퓨터 ↔ 라우터
```

### 핵심

```text
Crossover Cable
→ B ↔ A
→ 서로 다른 배열
→ 같은 기종 연결
```

---

# EIA/TIA 568-B

## 6. 568-B 색상 순서

책 기준:

```text
1 → 흰주황
2 → 주황
3 → 흰녹색
4 → 파랑
5 → 흰파랑
6 → 녹색
7 → 흰갈색
8 → 갈색
```

### 암기

```text
흰주 / 주
흰녹 / 파 / 흰파 / 녹
흰갈 / 갈
```

---

# EIA/TIA 568-A

## 7. 568-A 색상 순서

책 기준:

```text
1 → 흰녹색
2 → 녹색
3 → 흰주황
4 → 파랑
5 → 흰파랑
6 → 주황
7 → 흰갈색
8 → 갈색
```

---

## 8. 568-A와 568-B 비교

차이는 **주황 계열과 녹색 계열의 위치**이다.

```text
568-B

1 → 흰주황
2 → 주황
3 → 흰녹색
6 → 녹색
```

```text
568-A

1 → 흰녹색
2 → 녹색
3 → 흰주황
6 → 주황
```

공통:

```text
4 → 파랑
5 → 흰파랑
7 → 흰갈색
8 → 갈색
```

# 핵심 정리

```text
Router
→ 최적 경로 설정
→ 서로 다른 네트워크 연결
```

```text
Gateway
→ 서로 다른 통신망 / 프로토콜 중개
→ 데이터 포맷 중개
```

```text
Direct
→ 568-B ↔ 568-B
→ 다른 기종 연결
```

```text
Crossover
→ 568-B ↔ 568-A
→ 같은 기종 연결
```

```text
568-B
1 흰주
2 주
3 흰녹
4 파
5 흰파
6 녹
7 흰갈
8 갈
```

```text
568-A
1 흰녹
2 녹
3 흰주
4 파
5 흰파
6 주
7 흰갈
8 갈
```

## 시험 직전 암기

```text
Router = Route = 경로

```

```text

```

```text

→ 주황 먼저
```
