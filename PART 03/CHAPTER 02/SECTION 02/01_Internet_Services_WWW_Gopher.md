# Internet Services - WWW & Gopher

## 1. WWW

`WWW`는 **World Wide Web**의 약자이다.

HTTP(Hyper Text Transfer Protocol)를 기반으로 하며  
멀티미디어와 하이퍼텍스트를 통합한 정보 검색 시스템이다.

### 주요 특징

```text
HTTP 기반
멀티미디어 + 하이퍼텍스트
정보 검색 시스템
GUI 사용 가능
```

인터넷에 연결된 전 세계 컴퓨터의 문서를  
다양한 컴퓨터 환경에서 검색할 수 있도록 해 준다.

---

## 2. WWW의 역사

책 기준:

```text
1989년 CERN
→ 하이퍼텍스트 시작

1990년
→ WWW라는 NeXT 플랫폼용 브라우저 공개
```

### 핵심

```text
WWW
→ CERN
→ 1989 하이퍼텍스트
→ 1990 WWW 브라우저
```

---

## 3. WWW의 구조

WWW 서비스는 **분산 Client-Server 모델**을 기반으로 한다.

```text
WWW
→ Distributed Client-Server Model
```

---

## 4. WWW 관련 표준 웹 프로토콜

책에 나온 프로토콜:

```text
HTTP
XML
SOAP
WSDL
UDDI
```

서로 다른 개발 환경이나 운영체제에서도  
상호 통신이 가능하도록 지원한다.

---

# Gopher

## 5. Gopher 서비스

Gopher는 **인터넷 기반 정보 검색 서비스**이다.

책에서는 미국 **미네소타 대학교**에서 개발되었다고 설명한다.

```text
Gopher
→ 미네소타 대학교
→ 정보 검색 서비스
```

---

## 6. Gopher의 특징

인터넷상의 정보를 **계층적으로 분류**한다.

사용자는 서버의 주소를 모르더라도  
메뉴 방식의 인터페이스를 이용하여 정보를 찾을 수 있다.

```text
Gopher
→ 메뉴 방식
→ 계층적 정보 구조
→ 텍스트 기반
```

주요 특징:

```text
텍스트 기반 메뉴 인터페이스
터미널 환경 기반
정보를 계층적으로 분류
메뉴를 따라 하위 정보로 이동
대량 정보 검색 및 저장에 사용
```

---

## 7. Gopher의 쇠퇴

책에서는 1990년대 중반 이후 WWW가 널리 사용되면서  
Gopher가 주류에서 밀려났다고 설명한다.

웹 브라우저들도 점차 Gopher 지원을 중단하였다.

```text
Gopher
→ WWW 확산 이후 쇠퇴
```

---

# WWW와 Gopher 비교

| 구분 | WWW | Gopher |
|---|---|---|
| 주요 방식 | HTTP 기반 | 메뉴 방식 |
| 정보 구조 | 하이퍼텍스트 | 계층적 정보 |
| 인터페이스 | GUI 사용 가능 | 텍스트 기반 |
| 주요 특징 | 멀티미디어 지원 | 메뉴를 따라 정보 검색 |
| 역사 | CERN | 미네소타 대학교 |
